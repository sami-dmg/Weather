# Weather App 🌦️

A modern, native Android weather application built with Java that fetches real-time meteorological data and displays accurate location-based forecasts.

## ✨ Features
- **Real-Time Data:** Live weather fetching utilizing the OpenWeather API.
- **Dynamic UI:** Background layouts shift automatically based on current atmospheric conditions.
- **Location-Based:** Automatic or manual city search support.

## 🛠️ Tech Stack
- **Language:** Java
- **Framework:** Android SDK, Android Studio
- **API:** OpenWeather REST API
